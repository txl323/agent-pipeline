# 外部信息检索技能

## 适用场景
- 业务数据库之外的外部信息：新闻、行业资讯、技术资料、事实核查、实时信息（天气/汇率等）
- 搜索结果摘要不够、需要阅读全文时抓取网页正文
- 不适用：业务数据查询（用 data-query 技能）、文件导出（用 export-csv 技能）

## 前置条件
- 服务器可访问公网（httpx 直连，无需代理）
- 搜索源：cn.bing.com（HTML 抓取 + 正则解析，无 API Key）

## 工作流程
1. 提炼搜索关键词（用户问题 → 2-5 个关键词，不要整句搜索）
2. web_search 搜索，评估摘要是否足够回答
3. 摘要不够时 fetch_url 抓取关键页面正文（截断 8000 字符）
4. 汇总信息给出回复，引用真实 URL

## 参数契约
- **web_search(query, max_results)**：query 为搜索关键词；max_results 默认 5，最大 10。返回 [{title, url, snippet}]
- **fetch_url(url)**：url 为网页地址。返回正文纯文本（截断 8000 字符）

## 决策规则
1. 摘要足够回答时不必抓取全文，节省时间
2. 搜索无结果时换关键词/换写法重试（最多 2 次），不要原样重试
3. 需要深入阅读时只抓取与问题最相关的 1-3 个页面，不要批量抓取

## 失败处理
- 搜索失败：换关键词重试；仍失败时明确告知用户当前检索通道不可用，不编造结果
- 抓取失败（JS 渲染页面/反爬）：换其他来源页面；全部失败时如实说明
- 严禁凭记忆编造链接、数字或事实

## 输出约束
- 引用事实必须使用工具结果中出现的真实 URL
- 信息不足时明确说明，不猜测
- 回复中标注信息来源链接，便于用户核验
