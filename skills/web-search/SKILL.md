# 外部信息检索技能

## 能力清单

| 能力 | 说明 | 适用场景 |
|---|---|---|
| web_search | cn.bing.com 搜索，返回标题/链接/摘要 | 获取新闻、资料、事实等外部信息 |
| fetch_url | 抓取网页正文文本（截断 8000 字符） | 深入阅读搜索结果中的某个页面 |

## web_search 用法

参数 query（搜索关键词）、max_results（默认 5，最大 10）。返回 [{title, url, snippet}]。搜索无结果时换关键词重试。

## fetch_url 用法

参数 url（网页地址）。返回正文纯文本。用于搜索结果摘要不够、需要阅读全文的场景。

## 使用规范

- 引用事实必须使用工具结果中出现的真实 URL，严禁凭记忆编造链接
- 搜索失败时换关键词/换写法再试，不要原样重试
- 摘要足够回答时不必抓取全文

## 实现位置

脚本：scripts/web_search.py（httpx 抓取 + 正则解析）
